TokenMe is a local desktop assistant for AI development tools. Sign in with a card key, write compatible local configuration in one click, and keep working when quota is exhausted through refill and automatic account switching.

![TokenMe screenshot](assets/software-screenshot.png)

## Highlights

- **Unlimited refill**: continue after quota exhaustion with available capacity.
- **Multi-tool support**: Cursor, VS Code, Windsurf, Trae, Codex, cc-switch, and OpenAI-compatible tools.
- **Automatic switching**: retry with an available account when the current one is exhausted.
- **One-click setup**: generate local OpenAI-compatible configuration for detected tools.
- **In-app upgrades**: download and start the new installer from inside the app.
- **Model compatibility**: GPT-5.5, Image2, and other OpenAI-compatible models.
